OWASP Agentic Top 10 2026: 10가지 보안 위험과 핵심 대응

OWASP Agentic Top 10 2026의 공식 분류를 기준으로 목표 탈취, 도구 오용, 권한 악용 등 AI 에이전트의 10가지 위험과 핵심 대응을 정리합니다.

2026년 9월 20일10m

AI 에이전트는 주어진 목표를 바탕으로 작업을 선택하고, 도구를 사용하며 여러 단계의 실행을 이어가는 시스템입니다. 일부 단계에 사람의 승인이 있더라도 목표, 권한, 기억과 협업 과정에서 보안 위험이 발생할 수 있습니다.

OWASP Agentic Top 10은 이러한 에이전트 애플리케이션의 주요 보안 위험을 정리한 목록입니다. 이 글은 2025년 12월 공개된 2026판을 기준으로 각 항목의 의미와 핵심 대응을 요약했습니다. LLM Top 10을 보완하며, 자율적인 작업 수행과 도구 실행, 권한 위임에서 발생하는 위험에 초점을 둡니다.

ASI01 · Agent Goal Hijack

에이전트 목표 탈취는 공격자가 문서, 도구 응답, 외부 데이터 등에 지시를 심어 에이전트의 목표나 의사결정을 바꾸는 위험입니다. 조작된 입력은 이후 계획과 여러 단계의 작업 수행에도 영향을 줄 수 있습니다.

핵심 대응: 외부 콘텐츠를 신뢰할 수 없는 데이터로 취급하고, 실행할 작업이 원래 요청의 목적과 범위에 맞는지 모델 외부에서 검증합니다. 도구 권한을 제한하며, 목표 변경이나 영향이 큰 작업에는 별도의 검증·승인을 적용합니다.

ASI02 · Tool Misuse and Exploitation

도구 오용과 악용은 에이전트가 정상적인 도구를 허가된 권한 안에서 위험하거나 의도하지 않은 방식으로 사용하는 문제입니다. 불필요한 삭제, 과도한 API 호출, 내부 조회와 외부 전송 도구를 연결한 정보 유출 등이 포함됩니다.

핵심 대응: 도구별 기능, 접근 가능한 데이터, 호출량과 외부 전송 대상을 제한합니다. 실행 직전에 호출 목적과 인자를 검증하고, 삭제·송금·게시 등 영향이 큰 작업에는 변경 내용의 미리보기와 승인을 적용합니다.

ASI03 · Identity and Privilege Abuse

신원과 권한 악용은 에이전트의 인증정보나 신뢰·위임 관계를 악용해 허용되지 않은 접근과 작업을 수행하는 위험입니다. 상위 에이전트의 권한을 그대로 넘기거나 다른 사용자·작업의 인증정보를 재사용하는 구조가 원인이 될 수 있습니다.

핵심 대응: 에이전트별 신원을 구분하고 작업 범위와 유효기간이 제한된 인증정보를 사용합니다. 위임과 중요 동작마다 원래 사용자의 권한과 위임 범위를 다시 확인하며, 사용자·세션 간 인증정보를 분리합니다.

ASI04 · Agentic Supply Chain Vulnerabilities

에이전트 공급망 취약점은 외부 도구, 플러그인, 모델, 프롬프트, 다른 에이전트 등 공급받는 구성요소가 악성·취약하거나 변조되어 실행 과정에 유입되는 위험입니다. 설치된 패키지뿐 아니라 실행 중 발견하고 연결하는 도구와 서비스도 관리 대상입니다.

핵심 대응: 구성요소의 출처와 무결성을 확인하고 허용 목록, 버전 고정과 변경 검토를 적용합니다. 실행 중 구성 변경도 추적하며, 침해된 도구나 연결을 신속히 차단할 수 있도록 관리합니다.

ASI05 · Unexpected Code Execution (RCE)

예상하지 못한 코드 실행은 생성된 코드나 신뢰할 수 없는 입력이 충분한 검증 없이 실행되어 시스템을 침해하는 위험입니다. 셸 명령, 동적 코드 평가, 안전하지 않은 역직렬화와 템플릿 처리 등이 포함되며 원격 실행에만 한정되지 않습니다.

핵심 대응: 코드 생성과 실행 사이에 검증 단계를 두고, 운영 환경의 직접 실행과 위험한 동적 평가를 제한합니다. 비관리자 권한의 격리 환경에서 파일·네트워크 접근을 제한하고 실행 내역을 기록합니다.

ASI06 · Memory & Context Poisoning

메모리와 컨텍스트 오염은 저장·재사용되는 기억과 검색 문맥이 악성 데이터로 오염되는 위험입니다. 조작된 내용이 후속 판단과 도구 사용에 지속적으로 영향을 주며, 세션이나 에이전트 사이로 전파될 수 있습니다.

핵심 대응: 기억에 저장할 내용과 출처를 검증하고 사용자·업무별 기억을 분리합니다. 변경 이력을 관리하며, 오염된 항목을 격리·삭제하거나 신뢰할 수 있는 상태로 복구할 수 있도록 준비합니다.

ASI07 · Insecure Inter-Agent Communication

안전하지 않은 에이전트 간 통신은 메시지의 인증·무결성·검증이 부족해 협업 과정이 조작되는 위험입니다. 발신자 위조, 메시지 변조, 과거 메시지의 재전송 등이 잘못된 위임과 실행으로 이어질 수 있습니다.

핵심 대응: 상호 인증, 암호화와 메시지 무결성 검증을 적용합니다. 발신자의 권한, 메시지의 대상·업무 맥락·유효시간을 확인하고, 같은 요청이 반복 실행되지 않도록 중복과 재전송을 통제합니다.

ASI08 · Cascading Failures

연쇄 실패는 한 에이전트의 오류나 침해가 다른 에이전트와 연결된 업무로 전파·증폭되는 위험입니다. 잘못된 결과의 재사용, 반복 위임과 재시도 등이 결합하면 시스템 전체의 장애나 대규모 상태 변경으로 이어질 수 있습니다.

핵심 대응: 에이전트와 업무 간 실행 경계를 분리하고, 후속 작업에 전달할 결과를 검증합니다. 호출·재시도 횟수와 자원 사용량에 한도를 두며, 이상 시 자동 중단·격리하고 관련 작업을 추적·복구할 수 있도록 설계합니다.

ASI09 · Human-Agent Trust Exploitation

사람과 에이전트 사이의 신뢰 악용은 에이전트에 대한 사람의 신뢰와 과도한 의존이 잘못된 판단이나 승인에 이용되는 위험입니다. 자신감 있는 설명이나 조작된 근거가 위험한 권고를 신뢰하게 만들 수 있습니다.

핵심 대응: 실제 출처, 변경 대상과 영향을 검토자에게 보여주고 영향이 큰 작업은 독립적으로 확인합니다. 미리보기와 실행을 분리하고, 승인한 대상·내용과 실제 실행이 일치하도록 검증하며 승인 이력을 기록합니다.

ASI10 · Rogue Agents

목적과 통제를 벗어난 에이전트는 에이전트가 의도된 기능과 허용 범위를 이탈해 유해하게 행동하는 위험입니다. 외부 조작이나 잘못된 목표 설정 등이 시작점이 될 수 있으며, 개별 입력보다 이후 지속되는 행동 이탈과 통제 상실에 초점을 둡니다.

핵심 대응: 허용된 목표·행동과 실제 수행 내역을 지속적으로 비교합니다. 이상이 발견되면 에이전트를 격리하고 권한 회수·실행 중단을 적용하며, 위임된 작업과 대기 작업까지 확인한 뒤 검증된 상태로 복구합니다.

적용할 때 구분할 점

ASI02는 부여된 권한 안에서의 도구 오용, ASI03은 신원과 위임 관계를 악용한 권한 경계 침해에 초점을 둡니다. 한 사건에 목표 탈취, 기억 오염, 연쇄 실패가 함께 나타날 수 있으므로 항목을 서로 배타적인 분류로 볼 필요는 없습니다.

공통 원칙은 업무에 필요한 수준으로 자율성을 제한하는 최소 자율성(Least Agency)과 실행 과정을 추적할 수 있는 기록입니다. 요청한 목표, 권한 판단, 도구 호출, 승인과 실제 시스템 변경을 연결해 확인하고, 이상 시 실행을 중단·복구할 수 있어야 합니다.
